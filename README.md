## ARC – All-in-one Remote Console

ARC is a portable Linux-based console designed for developers, researchers, and security engineers who need a compact device for debugging, communication, and RF/NFC analysis in the field. It combines an Orange Pi Zero 2 W, a custom motherboard, integrated keyboard, 3.5" SPI display, audio, battery and power management into a single handheld tool.

### **What ARC offers**

- **Unified desktop environment**: Custom Python desktop (ARC DE) built with Pygame, optimized for a small touchscreen.
- **Built-in tools**: WiFi, Bluetooth, IR, RF, NFC utilities, terminal, calendar, music player, game launcher, and more.
- **Field-ready form factor**: 3D-printed enclosure, integrated keyboard, and battery-powered operation.

### **Getting started**

- **Setup & installation**: See `SETUP.md` and `INSTALL.md` for detailed installation and configuration steps.
- **Configuration**: Runtime behavior and app paths are configured via `arc/config/arc.yaml` on the device.
